# 🎯 Number Guessing Game (C++)

## 📌 Description

A modular Number Guessing Game built using C++ with Object-Oriented Programming concepts.
The game allows users to guess a randomly generated number with multiple difficulty levels, scoring system, and persistent high score storage.

---

## 🚀 Features

* 🎮 Difficulty Levels (Easy, Medium, Hard)
* 🔢 Random Number Generation
* ⏳ Limited Attempts
* 🧮 Score Calculation System
* 💾 High Score Saving (File Handling)
* ⏱ Execution Time Tracking
* ⚠ Input Validation
* 🔁 Replay Option

---

## 🛠 Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling
* Standard Template Library (STL)

```

```

### Run:

```

```
